# 灵枢（Lingshu）测试文档

**代码基线：** HEAD `e2353b0`（2026-08-19）
**测试日期：** 2026-08-20
**测试框架：** Python 标准库 `unittest`（含 `unittest.IsolatedAsyncioTestCase`），无 pytest 依赖

## 1. 测试目标

验证灵枢在授权安全测试场景下的功能完整性、状态一致性、权限边界、数据持久化、模型调用契约、MCP 接入与 Workspace 隔离。测试重点不是验证目标系统漏洞，而是验证本系统**不会越权执行、错误推进阶段、丢失过程记录或泄露会话数据**。

## 2. 测试范围

### 2.1 功能范围

- 状态机：合法迁移白名单、终态不可逆、非法迁移拒绝
- 审计链：SHA-256 前向哈希、篡改检测、持久化往返
- 审批闸门：AntSword MCP 只读/可写工具权限、审批状态联动
- 计划工具：SubmitPlan 原子批量、completed 证据强制、checkpoint 镜像
- 工具契约：StrictJSONToolkit 严格参数闸门、scoped_shell v2 流式 artifacts、破坏性命令拦截
- 记忆系统：长期记忆脱敏归档、上下文压缩契约（SUMMARY_SCHEMA）
- 持久化：session_store v3 schema、blob 引用、分页/批处理性能
- 模型契约：DeepSeek/GLM/Qwen/自定义 Provider 请求格式、版本钉住
- Workspace：会话隔离、路径逃逸防护、内容寻址 blob、TTL 回收
- 恢复：resume 语义、终态不重放、损坏检测
- 集成：AgentScope Service 事件翻译、AntSword 生命周期、IDA/GDB MCP 配置

### 2.2 不在范围内

- 未授权目标的攻击验证
- 第三方模型服务内部正确性
- 第三方 MCP 服务自身安全性
- 生产环境高并发容量认证（性能测试仅覆盖流式渲染与持久化批处理单元）

| 3 | `test_attack_cleanup_closes_only_its_mcp_session` | 契约漂移 | 测试 mock 的 `SimpleNamespace` 缺 `is_stateful` 属性；`agent/Attack.py:328` `close_attack_agent` 已新增该属性访问，mock 未同步 |

### 4.2 根因分类

- **环境依赖（2 个）**：`agentscope.app` 对 fastapi `on_startup` 的依赖与当前解释器实际加载的 fastapi 版本不一致。已验证补装 `apscheduler==3.11.3` 后错误前移为 `on_startup` 参数不兼容，确认与项目业务代码无关。建议：统一 fastapi 版本（对齐 `requirements.txt` 0.141.1 或验证 agentscope 2.0.6 支持的版本区间）。
- **契约漂移（5 个）**：实现演进后测试未同步。建议：更新 `test_qwen_contract.py` 断言到 `Parameters(thinking_enable / parallel_tool_calls)` 新契约；`test_attack_antsword_mcp.py` 的 mock 补齐 `is_stateful` / `is_connected` 属性。

## 7. 未覆盖项与建议

1. **无 CI 集成**：根目录无 `pyproject.toml` / `pytest.ini` / GitHub Actions。建议接入 CI（`pip install -r requirements.txt && python -m unittest discover -s tests`），并在 CI 固定 fastapi 版本。
2. **契约漂移治理**：建议为「模型请求构造」建立 golden 测试（断言最终 `Parameters` 而非内部 kwargs），避免实现演进后测试失配。
3. **环境一致性**：`.venv` 与实际 `requirements.txt` 不一致（曾缺 apscheduler、fastapi 版本漂移）。建议 `pip freeze` 对齐并纳入 CI 校验。
4. **未覆盖**：ScopeAuditor 审核规则、`_ApprovalBroker` 三态决策、`submit_slab_flag`、PDF 报告渲染、SSE 断线重连（端到端）、知识库维度热重载。建议补充针对这些模块的单元/集成测试。
5. **性能测试深度**：当前仅单元级（分页/批处理/流式节流）。建议补充长会话（>1000 消息）端到端渲染压测。
