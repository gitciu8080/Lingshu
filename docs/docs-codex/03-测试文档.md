# 灵枢·利刃Agent 测试文档

**项目类型：** 面向授权安全测试的多专家协作智能体  
**测试日期：** 2026-08-17  
**测试基线：** 分支 `2026-08-12`，HEAD `02419d3`

## 1. 测试目标

验证灵枢·利刃Agent 在授权安全测试场景下的功能完整性、状态一致性、权限边界、数据持久化、模型调用、MCP 接入和 WebUI 交互能力。

测试重点不是验证目标系统漏洞，而是验证本系统不会越权执行、错误推进阶段、丢失过程记录或泄露其他账户数据。

## 2. 测试范围

### 2.1 功能范围

- 登录、注册、JWT、超级管理员
- 会话创建、列表、删除、恢复和取消
- Brain/Orchestrator/Recon/Analysis/Attack/Reserve/Summary 协作
- 计划登记、更新、证据和终态收尾
- 人工审批、攻击阶段闸门和审批事件
- SSE、历史消息、推理持久化、工具历史
- RAG 初始化、检索、重建和维度校验
- AntSword、IDA、GDB MCP 生命周期
- PDF 报告和 JSONL 原始会话导出
- 亮色、暗色、液态玻璃和移动端布局

### 2.2 不在范围内

- 未授权目标的攻击验证
- 第三方模型服务内部正确性
- 第三方 MCP 服务自身的安全性
- 生产环境高并发容量认证

## 4. 测试用例

### 4.1 认证与权限

| 编号 | 场景 | 预期结果 |
|---|---|---|
| AUTH-01 | 无 Token 访问受保护接口 | 返回 401 |
| AUTH-02 | 过期或伪造 JWT | 返回 401，不执行任务 |
| AUTH-03 | 空邀请码注册 | 默认拒绝 |
| AUTH-04 | 错误邀请码注册 | 返回 403 |
| AUTH-05 | 弱密码注册 | 返回 400，不写入用户 |
| AUTH-06 | 重复用户名 | 不泄露“用户名已存在”细节 |
| AUTH-07 | 普通用户访问超级管理员接口 | 返回 403 |
| AUTH-08 | 用户读取其他用户会话 | 返回 404 或 403 |

### 4.2 任务和状态机

| 编号 | 场景 | 预期结果 |
|---|---|---|
| TASK-01 | 创建合法授权目标 | 生成独立 SessionContext 和 Workspace |
| TASK-02 | 非法目标或越界目标 | 创建失败，不进入 Agent |
| TASK-03 | Brain 登记计划 | 计划持久化并产生 plan_updated |
| TASK-04 | 非法阶段迁移 | 被 TaskState 拒绝 |
| TASK-05 | 攻击前未审批 | dispatch_attack 拒绝执行 |
| TASK-06 | 用户发送新情报 | 当前 Agent 被请求中断，消息进入队列 |
| TASK-07 | 取消运行中任务 | Agent/MCP 清理，任务进入 cancelled |
| TASK-08 | 完成任务后迟到取消 | 不覆盖 completed 成功终态 |
| TASK-09 | 进程异常后恢复 | 从检查点继续或标记 uncertain，不盲目重放 |

### 4.3 工具和 MCP

- 校验工具调用开始、参数增量、结束和输出均可见。
- 校验工具参数不因前端高度或滚动区域被截断。
- AntSword 只读工具无需攻击审批，写入/执行类工具必须审批。
- IDA/GDB 会话必须显式创建、使用和关闭。
- MCP 断开时任务应产生可解释错误，不应卡死或错误标记成功。

### 4.4 持久化与导出

- 刷新会话后恢复用户消息、Agent 回复、推理、工具参数和工具输出。
- `GET /api/session/{id}/jsonl` 导出首行会话元数据，后续每行是一个完整事件。
- PDF 报告使用中文字体，标题加粗，正文可读。
- 任务异常或 Summary Agent 失败时仍保留结构化摘要和任务终态。

### 4.5 知识库

- Milvus Collection 不存在时可初始化。
- Collection 为 released 时，搜索前执行 load 或返回清晰状态。
- 向量维度不匹配时不静默写入，提示重建派生索引。
- `.RAG` 源文件变化后可重新索引并更新哈希清单。

5. 对当前 `.RAG` 删除和数据库运行数据进行提交前脱敏审计。
