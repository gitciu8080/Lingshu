# 基线核查

> 关键词:安全基线,基线核查,等保2.0,GB/T 22239,CIS Benchmarks,OpenSCAP,lynis,CIS-CAT,核查清单,整改闭环,例外审批,核查频率,自动化核查,配置漂移

## 安全基线的概念与价值

安全基线(Security Baseline)是为满足安全要求,对系统、应用、网络设备的配置与状态设定的**最低安全标准**,是"必须达到"而非"建议做到"的集合。

- **概念**:基线 = 明确检查项 + 基线值(期望配置)+ 风险等级(高/中/低)。例如"SSH 禁止 root 登录"是检查项,"PermitRootLogin no"是基线值。
- **价值**:
  - 加固效果可度量:没有基线就无法判断"加固到什么程度算合格";
  - 等保测评有依据:测评结论依赖基线符合性核查;
  - 防止配置漂移:通过定期核查发现偏离,及时纠偏;
  - 整改有抓手:差距项直接转化为整改任务单。

## 常见基线标准

### 等保2.0(GB/T 22239-2019)

- 三级系统核心控制点:身份鉴别、访问控制、安全审计、入侵防范、恶意代码防范、集中管控等,对应主机/网络/应用/数据各层面。
- 等保测评报告中"不符合/部分符合"项即基线差距项;整改后需复测闭环。
- 常用配套:等保 2.0 基本要求 + 测评要求 + 实施指南。

### CIS Benchmarks

- CIS(Center for Internet Security)发布的各平台加固基线:Linux(RHEL/CentOS/Ubuntu)、Windows Server、Nginx、Docker、Kubernetes、云平台等。
- 每条建议含:级别(Level 1 常规/Level 2 高安全)、审计命令、修复方法;是落地性最强的公开基线。
- 工具:CIS-CAT Pro(官方核查工具,企业版收费);社区可用 `oscap` 加载 CIS 内容(需授权)。

### 行业与厂商规范

- 金融:银保监会《商业银行信息科技风险管理指引》、金融业网络安全等级保护实施指引。
- 运营商/电力/医疗等行业有本行业基线规范;云厂商(阿里云/腾讯云/AWS)提供云平台基线检查项(如 Alibaba Cloud CIS Benchmark)。
- 自建基线:结合等保+CIS+行业要求裁剪为本组织基线,保留"业务例外"审批机制(见下)。

## 基线核查内容

| 类别 | 典型检查项 |
| --- | --- |
| 账号口令 | 口令复杂度/有效期/锁定阈值、空口令、默认口令、UID=0 账户、共享账号、过期账号 |
| 权限 | sudo 授权、文件权限(600/640)、umask、SUID/SGID、属主属组、ACL |
| 服务 | 无用服务/端口、监听端口暴露面、未知进程、计划任务/启动项 |
| 补丁 | 系统补丁级别、组件/中间件版本、已知高危 CVE 覆盖 |
| 配置项 | SSH 配置、内核参数(sysctl)、防火墙规则、共享/SMB、SNMP、管理端口暴露、日志与审计开启 |
| 管理与审计 | 日志是否集中、审计规则是否生效、时间同步(NTP)、管理员双因素、变更留痕 |

## 核查方法

### 手工核查命令(抽查)

- Linux:`grep` 检查配置、`find / -perm -4000`、`ss -tlnp`、`systemctl list-unit-files`、`chage -l`、`getenforce`。
- Windows:`secpol.msc`、`auditpol /get`、`Get-Service`、`Get-HotFix`、`reg query`。
- 网络设备:`show running-config`、`show port-security`、`show ip dhcp snooping`、`show ntp status`。
- 优点:灵活、可解释;缺点:效率低、易遗漏,适合小范围或专项抽查。

### 脚本核查

- 将检查项固化为 Shell/PowerShell/Python 脚本,批量采集并输出"符合/不符合/风险等级"表格。
- 示例思路(Linux):

```bash
#!/bin/bash
echo "[1] root 远程登录:$(grep -c '^PermitRootLogin no' /etc/ssh/sshd_config)"
echo "[2] 口令有效期:$(grep '^PASS_MAX_DAYS' /etc/login.defs)"
echo "[3] SUID 数量:$(find / -perm -4000 -type f 2>/dev/null | wc -l)"
echo "[4] 监听端口:$(ss -tln | wc -l)"
```

- 优点:批量、可复用、可纳入 CI;缺点:需维护脚本与基线同步更新。

### 基线核查工具

| 工具 | 说明 | 使用示例 |
| --- | --- | --- |
| OpenSCAP | 开源 SCAP 核查引擎,支持等保/CIS/厂商 content | `oscap xccdf eval --profile xccdf_org.ssgproject.content_profile_cis /usr/share/xml/scap/ssg/...` |
| scap-security-guide(SSG) | Red Hat 提供的 SCAP 内容集,含 CIS/等保 profile | `yum install scap-security-guide` |
| lynis | 开源主机安全审计工具,输出硬化建议与分数 | `lynis audit system` |
| CIS-CAT | CIS 官方核查工具(Pro 收费,Assessor 免费精简版) | 加载 CIS Benchmark 模板生成报告 |
| 厂商基线核查工具 | 等保自查工具、云平台安全中心(阿里云/腾讯云/华为云基线检查)、华为/绿盟等厂商核查平台 | 控制台一键核查 |
| 自研采集平台 | 按本组织基线开发的核查平台,对接 CMDB 与工单 | 批量下发采集 |

OpenSCAP 核查示例:

```
# 安装
yum install openscap-scanner scap-security-guide -y
# 列出 profile
oscap info /usr/share/xml/scap/ssg/content/ssg-centos7-ds.xml | grep -i profile
# 执行核查并生成报告
oscap xccdf eval --profile xccdf_org.ssgproject.content_profile_cis \
  --report /tmp/scan-report.html \
  /usr/share/xml/scap/ssg/content/ssg-centos7-ds.xml
```

lynis 示例:

```
apt install lynis        # 或 yum install lynis
lynis audit system       # 全系统审计
# 输出 /var/log/lynis-report.dat 与建议列表,评分 0-100
```

## 基线核查报告与整改闭环

### 报告要素

- 资产范围、核查标准与版本、核查时间与工具;
- 逐项结果:符合/不符合/不适用,附风险等级与证据(命令输出截图/文件路径);
- 汇总统计:符合率、高危/中危/低危差距项数量;
- 整改建议:每项差距给出修复命令/配置修改与验证方法。

### 整改闭环流程

```
核查 → 报告 → 差距项定级 → 整改任务分派(责任人/期限)
     → 整改(按修复建议执行)→ 复测验证 → 状态更新(基线台账)
     → 无法整改的走例外审批 → 定期再核查(防回退)
```

- 高危项(可被直接利用,如空口令、默认口令、SSH 密码认证开启)限期整改(如 7 天内);
- 中危项(如弱密码策略、未开审计)限期整改(如 30 天内);
- 复测不合格继续跟踪,纳入安全运营周报;
- 整改记录(变更单号、时间、人)留痕,便于追溯。

## 基线差异化场景(例外审批)

- 业务确实无法满足某基线项时,走**例外审批**:业务方提出 → 安全评审 → 记录补偿控制措施 → 管理层批准 → 设置例外有效期(如 90 天)并定期复审。
- 补偿控制示例:无法关 SSH 密码认证(旧客户端)→ 用网络 ACL 限定来源 + 加双因素 + 限速;无法打补丁的老系统 → 虚拟补丁+隔离(见《补丁与配置管理.md》)。
- 例外台账要纳入核查报告:核查时对例外项单独展示,防止"例外交了,基线丢了"。

## 核查频率与自动化

- **频率建议**:高危资产/对外系统每月核查;一般系统季度核查;重保/护网前全量核查;新系统上线前必须核查。
- **自动化**:
  - 定时任务批量采集 + 结果入库,自动比对基线生成差距清单;
  - 与 CI/CD 集成:镜像/配置模板上线前跑基线检查,不合格阻断发布;
  - 与 CMDB 联动:资产变更后自动触发核查,发现漂移自动告警;
  - 与工单系统联动:差距项自动生成整改任务,闭环可追踪。
- 基线本身也要版本化维护:随新版本系统、新威胁、等保新要求定期修订,修订记录留档。

## 基线核查清单模板(示例片段)

| 检查项 | 基线值 | 风险等级 | 核查方式 |
| --- | --- | --- | --- |
| SSH root 登录 | PermitRootLogin no | 高 | grep sshd_config |
| SSH 密码认证 | PasswordAuthentication no(或限来源) | 高 | grep sshd_config |
| 口令最大有效期 | <=90 天 | 中 | grep /etc/login.defs |
| 锁定策略 | 5 次失败锁定 | 中 | grep pam_faillock |
| SUID 高危文件 | 仅白名单 | 高 | find / -perm -4000 |
| 防火墙默认策略 | 默认拒绝 | 高 | firewall-cmd --list-all |
| 审计规则 | 关键路径有 -w 规则 | 中 | auditctl -l |
| SELinux | enforcing | 中 | getenforce |
| 补丁级别 | 无高危 CVE 未修 | 高 | 漏洞扫描/台账 |
