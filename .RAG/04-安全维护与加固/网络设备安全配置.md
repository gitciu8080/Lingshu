# 网络设备安全配置

> 关键词:网络设备加固,防火墙策略,默认拒绝,区域划分,交换机安全,端口安全,VLAN隔离,DHCP Snooping,DAI,STP,防环路,路由器加固,ACL,SSH,远程管理,双因素,设备口令,SNMPv3,NTP,日志集中,网络分段,DMZ,微隔离,云安全组,网络ACL

## 概述
网络设备(防火墙、交换机、路由器)是网络的第一道防线与东西向流量的控制点。加固目标是:缩小管理面暴露、收敛放行策略、阻断未授权访问、留存审计日志。所有配置遵循"默认拒绝、最小放行、区域隔离"三大原则。下文示例以华为(USG/S系列)与思科 IOS 两种常见语法给出,实际以设备型号手册为准。

## 防火墙策略设计

### 最小化放行与默认拒绝

- 防火墙策略以业务白名单为准:默认拒绝所有流量,仅放行业务必需的五元组(源 IP、目的 IP、协议、源端口、目的端口)。
- 每条放行策略必须有业务依据、申请人、有效期;每季度梳理清理过期策略。
- 策略次序:精确规则在前、宽泛规则在后;保持"显式 allow、隐式 deny"风格,拒绝规则放最后兜底。

华为 USG 示例:

```
# 默认拒绝(兜底)
rule name deny-all
  action deny

# 放行办公网访问 DMZ Web
rule name allow-oa-to-web
  source-address 10.10.0.0/16
  destination-address 192.168.1.0/24
  service https
  action permit

# 放行运维网段管理设备
rule name allow-ops-to-mgmt
  source-address 10.99.0.0/24
  service ssh https
  action permit
```

### 区域划分

- 物理/逻辑划分安全域,域间流量全部经防火墙控制:**外网区(Untrust)、DMZ区、内网区(Trust)、管理区(MGMT)**。
- 典型策略:Untrust→DMZ 仅放行对外服务端口(80/443/邮件);Untrust→内网 默认拒绝;DMZ→内网 仅放行业务必需端口;管理区仅对运维网段开放。
- 域内(内网内部)东西向流量同样需要控制,必要时启用微隔离(见"网络拓扑分段")。

## 交换机安全

### 端口安全(Port Security)

限制接入端口允许的 MAC 数量,防私接设备/交换机:

```
# 思科
interface GigabitEthernet0/1
 switchport mode access
 switchport port-security
 switchport port-security maximum 2
 switchport port-security violation shutdown   # 违规即 shutdown
 switchport port-security mac-address sticky   # 动态学习并固化

# 华为
interface GigabitEthernet0/0/1
 port-security enable
 port-security max-mac-num 2
 port-security protect-action shutdown
```

建议:接入端口一律 access + port-security;上联端口不启用端口安全或只绑定对端设备 MAC。

### VLAN 划分与隔离

- 按部门/业务划分 VLAN,广播域与故障域最小化;不同信任级别的区域必须不同 VLAN。
- 用户 VLAN 与服务器 VLAN、管理 VLAN 严格分离;管理 VLAN 独立(如 VLAN 99),仅管理网段可达。
- 跨 VLAN 路由统一经防火墙/三层交换机 ACL 控制,禁止直接互通。
- 禁用不必要的 trunk 口;trunk 上配置 `allowed vlan` 白名单,不允许多余 VLAN 通过。

```
# 思科 trunk 收紧
interface GigabitEthernet0/24
 switchport trunk encapsulation dot1q
 switchport mode trunk
 switchport trunk allowed vlan 10,20,99
 switchport nonegotiate
```

### DHCP Snooping(防 DHCP 欺骗)

信任上联端口,非信任端口限速并校验 DHCP 报文:

```
# 思科
ip dhcp snooping vlan 10,20
ip dhcp snooping
interface GigabitEthernet0/24          # 上联
 ip dhcp snooping trust
interface range GigabitEthernet0/1-23  # 接入
 ip dhcp snooping limit rate 5

# 华为
dhcp enable
dhcp snooping enable
interface GigabitEthernet0/0/24
 dhcp snooping trusted
interface GigabitEthernet0/0/1
 dhcp snooping enable
 dhcp snooping max-user-number 5
```

### 动态 ARP 检测 DAI(防 ARP 欺骗/中间人)

依赖 DHCP Snooping 绑定表,校验 ARP 报文的 IP-MAC 一致性:

```
# 思科
ip arp inspection vlan 10,20
ip arp inspection validate src-mac dst-mac ip
interface GigabitEthernet0/24
 ip arp inspection trust          # 上联/服务器口信任

# 华为(IPSG + ARP 绑定检查)
arp anti-attack check user-bind enable
arp anti-attack check user-bind check-item ip-address mac-address
```

### 防环路(STP 加固)

- 启用 RSTP/PVST/MSTP;全网拓扑收敛,无环路。
- 接入端口开启 BPDU Guard(收到 BPDU 即 shutdown)与 Root Guard(防根桥抢占):

```
# 思科
interface range GigabitEthernet0/1-23
 spanning-tree bpduguard enable
 spanning-tree guard root
spanning-tree portfast default       # 仅限纯接入端口
```

- 启用 LoopGuard 与 UDLD(光纤链路单向故障检测);禁用无用的 port-channel 聚合口。

## 路由器加固

### 管理接口保护

- 关闭不需要的服务:CDP/LLDP(如无需求)、HTTP 管理、SNMP(见下)、小服务(echo/chargen)。

```
# 思科
no service tcp-small-servers
no service udp-small-servers
no ip http server
no cdp run
```

- 禁止远程重定向与源路由包:`no ip source-route`;控制面保护(Control Plane Policing)限制管理协议速率。

### ACL 示例(入口过滤)

思科:

```
access-list 100 deny ip any any log
access-list 100 permit tcp host 10.99.0.10 any eq 22       # 仅堡垒机 SSH
access-list 100 permit tcp 10.0.0.0 0.0.0.255 any eq https
interface GigabitEthernet0/0/1
 ip access-group 100 in
```

华为:

```
acl number 3000
 rule 5 permit tcp source 10.99.0.0 0.0.0.255 destination-port eq 22
 rule 10 deny ip
interface GigabitEthernet0/0/1
 traffic-filter inbound acl 3000
```

原则:ACL 用于"入口过滤 + 管理面收敛",不是替代防火墙;反私网源地址(BCP38)在边界入口 deny 源为 RFC1918 的报文。

## 远程管理安全

### SSH 替代 Telnet

- 全网禁用 Telnet、HTTP、TFTP 管理,统一 SSHv2;VTY 只允许 SSH 输入。

```
# 思科
line vty 0 4
 transport input ssh
ip ssh version 2
ip ssh authentication-retries 3
ip ssh time-out 60
```

### 管理网段隔离

- 管理面(SSH/SNMP/日志/带外)单独划管理网段/管理 VRF,仅运维网段可达;管理口不接业务网。
- 生产设备 ACL 只放行运维网段访问管理端口;管理流量与业务流量分离。
- 建议经堡垒机(Jump Server)统一入口,记录会话审计。

### 双因素认证

- 接入 AAA:TACACS+ 或 RADIUS,结合 OTP 令牌实现双因素;本地账号仅作应急 fallback。

```
# 思科 AAA 示例
aaa new-model
aaa authentication login default group tacacs+ local
aaa authorization exec default group tacacs+ local
tacacs-server host 10.99.0.10 key <secret>
```

## 设备账号与口令策略

- 删除默认账号与默认口令(admin/admin、cisco/cisco、Huawei/huawei 等);出厂口令一律修改。
- 口令复杂度:长度>=12,含四类字符;启用口令老化(90 天)与失败锁定;口令以密文存储(`enable secret`、`irreversible-cipher`)。
- 特权账号分权:只读账号(monitor)与读写账号(admin)分离;按角色授权(RBAC/视图)。
- 本地账号最小化,优先 AAA 集中认证;离职人员账号立即回收。
- 示例:

```
# 思科
enable secret <strong-hash>
username ops privilege 5 secret <strong>
# 华为
local-user ops password irreversible-cipher <strong>
local-user ops privilege level 3
```

## 日志与 NTP

- 设备日志集中发送到日志服务器(Syslog),配置时间戳与源地址;关键日志(登录、配置变更、接口 up/down、ACL 命中)全部上送。

```
# 思科
logging host 10.99.0.10
logging trap informational
service timestamps log datetime localtime
# 华为
info-center loghost 10.99.0.10
info-center enable
```

- 全网 NTP 校时,保证日志与审计时间一致(等保要求):

```
# 思科
ntp server 10.99.0.20
# 华为
ntp-service unicast-server 10.99.0.20
```

- 配置变更自动备份:定期(每日)抓取 running-config 存配置管理服务器,与 CMDB 比对漂移(见《补丁与配置管理.md》)。

## SNMP 安全

- 优先 **SNMPv3(认证+加密)**,禁用 v1/v2c;确需 v2c 时修改 community 并限定来源。

```
# 思科:SNMPv3
snmp-server group mgmt v3 priv
snmp-server user monitor mgmt v3 auth sha <pwd> priv aes 256 <pwd>
snmp-server host 10.99.0.10 version 3 priv monitor

# 思科:v2c 收紧(如仅监控系统需要)
snmp-server community Str0ngR0 RO 99
access-list 99 permit 10.99.0.0 0.0.0.255
```

- 只读优先;写权限(RW)仅限必要且限来源;SNMP 管理网段仅监控服务器可达;禁用 SNMP set(写)除非必要。

## 网络拓扑分段

- **内网分区**:办公区、生产区、测试区、开发区物理/逻辑隔离;区间接防火墙,按业务白名单放行。
- **DMZ**:对外服务(Web/邮件/门户)部署在 DMZ,与内网严格隔离;DMZ 被攻破不得直连内网。
- **管理区**:集中运维网段,唯一可管理所有设备/服务器;管理流量经堡垒机。
- **微隔离(Micro-segmentation)**:对数据中心/云内部按应用维度做主机级策略(NSX、云防火墙、主机防火墙),控制东西向横向移动;典型场景:应用间只开业务端口,数据库仅应用服务器可达。

```
DMZ 典型流量模型:
Untrust --80/443--> DMZ-Web
DMZ-Web --sql(3306,限源)--> 内网-DB
内网-DB --拒绝--> 外网(仅出站白名单)
```
## 云环境安全组与网络 ACL

- **安全组(Security Group)**:云服务器实例级状态化防火墙;入方向默认拒绝,按业务最小放行(如 80/443 全网、22 仅堡垒机);出方向按业务白名单(如仅目标数据库/对象存储网段)。

```
# 以腾讯云/阿里云安全组规则为例(逻辑)
入方向:
  0.0.0.0/0    TCP 443     允许   # Web
  0.0.0.0/0    TCP 80      允许
  <堡垒机IP>   TCP 22      允许   # 管理
  其余                     拒绝
出方向:
  <DB子网>     TCP 3306    允许
  <对象存储>   TCP 443     允许
  其余                     拒绝
```

- **网络 ACL(Network ACL)**:子网级无状态过滤,先 deny all 再显式放行;安全组与网络 ACL 叠加使用,安全组更细、ACL 兜底边界。
- **云防火墙/云 WAF**:在云边界叠加 CFW、云 WAF 与 DDoS 防护;对公网暴露面做资产测绘收敛。
- 定期审计安全组:发现"0.0.0.0/0 全端口"等宽松规则立即收敛;安全组变更纳入变更审批与配置审计。
