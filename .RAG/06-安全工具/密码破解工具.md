# 密码破解工具

> 关键词:密码破解,hashcat,John the Ripper,哈希识别,哈希类型,字典攻击,掩码攻击,规则攻击,rockyou,GPU破解,彩虹表,Windows哈希,SAM,Linux shadow,WiFi握手,WPA2,aircrack-ng,airodump-ng,弱口令

密码破解用于安全审计场景:验证弱口令策略、评估密码哈希强度、应急响应中解锁取证数据。本文件覆盖离线哈希破解(hashcat/John)、口令提取方法(仅授权)、WiFi 握手破解与哈希类型速查。**红线:破解对象必须是本人账号、审计授权范围内的哈希,或公开 CTF/练习靶场数据;对他人账号口令进行破解属违法犯罪。**

## 哈希识别(破解前第一步)

- **用途**:识别哈希类型(算法)才能选择正确的 hashcat mode / john format,识别错误则破解必然失败。
- **识别方法**:
  - 看格式:前缀(`$2y$`/`$6$`/`$1$`/`$apr1$` 为 bcrypt/sha512crypt/md5crypt/apr1)、长度(32 hex=MD5,40 hex=SHA1,64 hex=SHA256/ SHA512)、`{SSHA}`、`{SHA512-CRYPT}` 等;
  - 工具:`hashid <hash>`、`hashcat --identify <hash>`(新版本支持)、John 的 `john --list=formats` 结合观察。
- **常用识别命令**:
```bash
hashid '$6$salt$hash'                       # 输出可能类型列表
hashcat --identify '$2y$05$...'             # hashcat 自动识别
```
- **常见陷阱**:同一长度多种算法(40 位可能是 SHA1 或 RIPEMD160);带盐哈希需确认盐的位置(如 `$salt$hash` 或 `salt:hash`);NT hash(Windows)是"无盐 MD4",格式固定 32 位 hex。

## hashcat(GPU 高速破解)

- **用途**:开源密码恢复工具,利用 GPU(CUDA/OpenCL)并行计算,是目前最快的离线破解方案;支持 300+ 哈希模式与 6 种攻击模式。
- **安装**:官网下载 hashcat 二进制;Linux 包 `apt install hashcat`;GPU 驱动需安装(NVIDIA 驱动 + CUDA 或 OpenCL)。
- **核心参数**:
  - `-m`:哈希模式(见速查表);
  - `-a`:攻击模式(0 字典 / 1 组合 / 3 掩码 / 6 字典+掩码 / 7 掩码+字典);
  - `-o`:输出文件;`--show`:查看已破解;`-w 3`:工作负载(1~4,越大越占资源);`--force`:忽略警告(如 CPU 模式)。
- **字典攻击(基础)**:
```bash
hashcat -m 1000 -a 0 ntlm.txt rockyou.txt          # NTLM 哈希跑 rockyou
hashcat -m 0 -a 0 md5.txt dict.txt -r rules/best64.rule   # 字典+规则
```
- **规则攻击(效率关键)**:规则在字典基础上衍生变体(大小写、加数字、加年份、leet 替换),规则文件位于 `rules/`:
```bash
hashcat -m 0 -a 0 hashes.txt rockyou.txt -r rules/best64.rule -r rules/d3ad0ne.rule
# 自定义规则示例文件 my.rule:
c $1 $2 $3        # 首字母大写 + 追加123
$1 $9 $9 $0       # 追加1990
sa@               # a 替换为 @
```
- **掩码攻击(暴力/半暴力)**:
```bash
hashcat -m 0 -a 3 hashes.txt '?l?l?l?l?d?d'        # 4小写+2数字
hashcat -m 0 -a 3 hashes.txt '?u?l?l?l?l?l?d?d?s'  # 常见口令模式
hashcat -m 0 -a 3 hashes.txt '?a?a?a?a?a?a?a?a' --increment   # 1~8位全字符递增
```
  - 掩码字符:`?l` 小写、`?u` 大写、`?d` 数字、`?s` 特殊字符、`?a` 全字符、`?h` 十六进制小写;自定义字符集 `-1 ?l?d` 后 `?1` 引用。
- **组合与混合攻击**:
```bash
hashcat -m 0 -a 1 hashes.txt word1.txt word2.txt   # 两个字典两两拼接
hashcat -m 0 -a 6 hashes.txt dict.txt '?d?d?d'     # 字典词 + 3位数字
hashcat -m 0 -a 7 hashes.txt '?d?d' dict.txt       # 3位数字 + 字典词
```
- **GPU 使用要点**:`hashcat -I` 查看设备,`-D 1`/`-D 2` 选择 GPU/CPU;多卡 `-d 1,2`;破解前 `--potfile-path` 指定进度文件,中断后可 `--show` 恢复查看;电源/散热注意,工作站负载长时间满载。
- **输出解读**:`Cracked: 12/100` 与进度条;破解口令显示在输出与 potfile;未破解的换规则/掩码策略继续,或放弃(强度高、成本不划算)。

## John the Ripper(JtR)

- **用途**:老牌密码破解工具,支持大量格式,内置"单模式(single)"与词表生成;与 hashcat 互补(某些格式/平台更顺手,含 Jumbo 版)。
- **安装**:`apt install john`(基础版);Jumbo 版从 GitHub openwall/john 构建(功能全)。
- **常用用法**:
```bash
john --wordlist=rockyou.txt hash.txt                # 字典破解,自动识别格式
john --format=sha512crypt --wordlist=dict.txt shadow.txt
john --single hash.txt                              # single 模式(用账号名等信息生成猜测)
john --incremental hash.txt                         # 增量(暴力)模式
john --show hash.txt                                # 显示已破解
john --rules=All --wordlist=dict.txt hash.txt       # 内置规则集
```
- **输出解读**:破解口令默认不直接显示,须 `--show` 或 `--pot` 查看 pot 文件;`Loaded X password hashes` 会提示识别到的格式;`0g 0:00:00:05` 表示已破解数量与耗时。
- **与 hashcat 分工**:JtR 适合小批量、格式杂、单模式快速试探;hashcat 适合大批量 GPU 高速破解。

## 在线彩虹表与字典资源

- **彩虹表(预计算哈希表)**:适用于**无盐**快速哈希(MD5、NTLM 等),超大表 + 索引实现秒级反查;常见资源:MD5Decrypt、CrackStation(在线)、RainbowCrack(`rtgen`/`rcrack` 本地生成,成本高,现代场景多被 GPU 直破替代)。**注意**:带盐哈希(bcrypt/sha512crypt/WPA2)彩虹表无效。
- **字典资源**:
  - `rockyou.txt`:Kali 内置 `usr/share/wordlists/rockyou.txt.gz`(1400 万口令),先 `gunzip`;新手必用基线字典。
  - 其他:SecLists(含用户名、口令、Web 目录等大类)、danielmiessler/SecLists GitHub;国内常用"CSDN 弱口令字典合集"(注意来源可信度)。
  - 定制字典:结合目标信息(公司名、域名、年份)生成,`crunch`(掩码生成)或 `cewl`(从网站爬词):
```bash
crunch 8 8 abc123 -o words.txt                    # 8位字符集生成
cewl https://example.com -m 6 -w cewl.txt         # 从站点提取单词(仅授权)
```
- **使用原则**:先字典→再规则→再掩码→最后纯暴力;避免无脑全量暴力(成本指数级);口令复用分析(同一批哈希交叉命中)是审计重点。

## 破解策略(字典 → 规则 → 掩码 → 暴力)

1. **字典**:最快,命中率取决于字典质量与目标习惯(默认口令、常见弱口令)。
2. **规则**:对字典词变形,性价比最高,优先尝试 `best64`、`rockyou30000` 等规则集。
3. **掩码**:针对已知口令模式(如 `8位小写+数字`、`首字母大写+6位+特殊符号`),按概率排序组合。
4. **纯暴力**:最后手段,仅对低熵口令可行;先评估密钥空间:`26^8` 与 `95^8` 数量级差异巨大,时间成本可能达数年,应直接放弃并改策略。
- **时间预算表(参考,RTX 4090,MD5)**:全小写 8 位≈分钟级;小写+数字 8 位≈小时级;全字符 8 位≈不可行(年/世纪级)。带盐慢哈希(bcrypt/argon2)速度慢千倍以上,暴力基本无望,只能靠字典。
- **要点**:先跑快哈希、先跑弱口令集合、善用 `--increment` 递增;多目标批量破解优先处理"最容易"的,往往能发现口令复用链。

## Windows / Linux 密码提取(仅授权)

- **Windows(SAM/NTDS)**:
  - 本地哈希提取(需管理员):注册表导出 SAM/SYSTEM,或用 Mimikatz(见[渗透框架与利用工具.md](渗透框架与利用工具.md))`privilege::debug` + `sekurlsa::logonpasswords` / `lsadump::sam`;
  - 域环境:`secretsdump.py -ntds ntds.dit -system SYSTEM LOCAL`(Impacket)导出全部域账号哈希;
  - 破解:NT hash(无盐 MD4)用 `hashcat -m 1000 -a 0`;LM hash(旧系统,`-m 3000`)已废弃但若存在可秒破。
- **Linux(/etc/shadow)**:
  - 提取:`cat /etc/shadow`(需 root);格式 `user:$6$salt$hash:...`(`$6$`=sha512crypt,`$5$`=sha256crypt,`$1$`=md5crypt,`$y$`=yescrypt 新默认);
  - 破解:JtR `john shadow.txt`(自动识别)或 hashcat `-m 1800`(sha512crypt)、`-m 7400`(sha256crypt)、`-m 500`(md5crypt)、`-m 15300`(yescrypt);
  - 要点:shadow 带盐,彩虹表无效;口令策略强的系统(如 16 位随机)直接放弃,转为检查弱口令与复用。
- **注意事项**:提取与破解仅限授权审计;哈希属于敏感数据,处理过程加密存储、用后销毁;提取本身即敏感操作,先取得书面授权。

## WiFi 握手破解(aircrack-ng 套件)

- **用途**:评估 WPA/WPA2 无线网络口令强度(仅限本人网络或获授权评估);原理:抓取四次握手(4-way handshake)后离线破解 PSK。
- **安装**:`apt install aircrack-ng`(含 aircrack-ng、airodump-ng、aireplay-ng、airmon-ng 等)。
- **典型流程**:
```bash
sudo airmon-ng start wlan0                          # 网卡进入监听模式(接口变 wlan0mon)
sudo airodump-ng wlan0mon                           # 扫描周围 AP,记下目标 BSSID/CH
sudo airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w cap wlan0mon   # 锁定信道抓包
# 若无人连接,可用 aireplay-ng 发送 deauth 促使客户端重连(注意合规与影响):
sudo aireplay-ng -0 5 -a AA:BB:CC:DD:EE:FF wlan0mon
# 当界面出现 "WPA handshake: AA:BB:CC:DD:EE:FF" 即抓到手握,ctrl+c 停止
sudo aircrack-ng -w rockyou.txt cap-01.cap          # 离线破解握手包
```
- **输出解读**:破解成功显示 `KEY FOUND! [ 口令 ]`;失败则提示"0 handshake"或字典未命中;可换更大字典/规则集(`aircrack-ng ... -w dict -r rule` 支持规则)或评估改用 WPA3(无 4-way handshake,需 SAE,难度大幅上升)。
- **注意**:WPA2 破解本质是"弱口令问题",强随机口令不可破解;`aireplay-ng -0` 的 deauth 攻击会影响在线用户,仅限授权演练;监听模式需网卡支持(monitor mode)。

## 哈希类型速查表(常见 hashcat mode)

| 哈希 | hashcat -m | 说明 | 破解速度参考 |
| --- | --- | --- | --- |
| MD5 | 0 | 无盐,极快 | 百亿级/s(GPU) |
| SHA1 | 100 | 无盐 | 十亿级/s |
| SHA256 | 1400 | 无盐 | 十亿级/s |
| NTLM | 1000 | Windows 口令哈希(无盐 MD4) | 百亿级/s |
| LM | 3000 | 旧 Windows,可秒破 | 极快 |
| md5crypt(Unix $1$) | 500 | 带盐,慢 | 千万级/s |
| sha256crypt($5$) | 7400 | 带盐 | 百万级/s |
| sha512crypt($6$) | 1800 | 带盐 | 十万~百万级/s |
| bcrypt($2a/$2b$) | 3200 | 自带盐,很慢,抗 GPU | 万级/s |
| yescrypt($y$) | 15300 | 新版 Linux 默认 | 万级/s |
| Argon2 | 25600/25700 | 现代抗 GPU | 千级/s |
| WPA-PBKDF2(握手) | 22000 | 需 .hccapx/.hc22000 转换 | 万级/s |
| Apache $apr1$ | 1600 | htpasswd | 百万级/s |
| Cisco-IOS/MD5 | 500 | 设备口令 | 同 md5crypt |

- **转换工具**:`hashcat` 配套 `cap2hccapx`/`hcxpcapngtool`(抓包转 hashcat 格式);`john` 直接吃多数格式。
- **速查技巧**:不确定类型先 `hashid` + `john --format=list` 对照;破解前用小样本(如已知口令构造的哈希)验证参数正确,避免空跑。

## 合规与安全提示

- 仅破解授权范围内的哈希;口令提取工具(Mimikatz 等)本身即高危工具,使用须留痕。
- 审计结果用于:评估口令策略、发现弱口令与复用、整改加固;不用于任何未授权访问。
- 破解出的口令属于敏感信息,按机密数据处理,报告脱敏(如只报"命中弱口令,已整改")。
