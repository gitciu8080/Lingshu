# 信息收集工具

> 关键词:信息收集,子域名枚举,subfinder,amass,dnsx,oneforall,DNS查询,dnsrecon,端口扫描,nmap,masscan,指纹识别,httpx,whatweb,空间测绘,Shodan,Fofa,目录枚举,ffuf,gobuster,证书透明日志,crt.sh,Git泄露,gitleaks

信息收集是渗透测试与资产测绘的第一步,目标是在授权范围内最大化摸清目标资产面:域名、IP、端口、服务、指纹、目录、泄露源码。本文件按"域名 → 端口 → 服务 → 应用"的递进顺序组织工具。所有探测均须在授权范围内进行。

## 子域名枚举

子域名是扩大资产面的主要途径,常见子域往往部署了测试环境、后台或未加固应用。

### subfinder(被动枚举,首选)

- **用途**:通过证书透明日志、DNS 数据集、威胁情报等被动源收集子域名,速度快、不直接触达目标(降低被发现风险)。
- **安装**:`go install github.com/projectdiscovery/subfinder/v2/cmd/subfinder@latest`,或 GitHub Releases 下载二进制;配置 API key 于 `~/.config/subfinder/provider-config.yaml` 可显著提升覆盖率。
- **核心命令**:
```bash
subfinder -d example.com -all -silent -o subs.txt
subfinder -d example.com -recursive   # 递归枚举,结果更多但更慢
```
- **输出解读**:每行一个子域名;`-all` 使用全部被动源,`-silent` 只输出域名便于管道处理。结果建议再交给 dnsx 验证存活。

### amass(深度被动枚举)

- **用途**:OWASP 项目,被动源最全、支持主动枚举与图数据库,适合大规模资产测绘;速度慢,适合离线批量。
- **安装**:`go install -v github.com/owasp-amass/amass/v4/...@master`,或下载 Releases。
- **核心命令**:
```bash
amass enum -passive -d example.com -o amass.txt
amass enum -active -d example.com -brute -w /usr/share/wordlists/amass/subdomains.txt
```
- **输出解读**:`amass db -show -d example.com` 可查看入库结果;主动模式(`-active`/`-brute`)会向目标 DNS 发包,注意授权与速率。

### dnsx(子域存活验证)

- **用途**:ProjectDiscovery 出品,快速验证子域解析、批量获取 A/CNAME 记录,常与 subfinder 管道组合。
- **安装**:`go install github.com/projectdiscovery/dnsx/cmd/dnsx@latest`。
- **核心命令**:
```bash
cat subs.txt | dnsx -a -resp -silent -o live.txt        # 验证解析并回显 IP
cat subs.txt | dnsx -cname -resp -silent                 # 关注 CNAME,发现云资产接管点
subfinder -d example.com -silent | dnsx -a -resp | tee live_subs.txt
```
- **输出解读**:重点关注解析到未托管/可接管服务(如已被删除的 S3、Azure 存储)的 CNAME 记录,可能存在子域接管漏洞。

### OneForAll(国产综合工具)

- **用途**:Python 编写的集成式被动子域收集工具,内置多源 API 与爆破,输出 xlsx 报告。
- **安装**:
```bash
git clone https://github.com/shmilylty/OneForAll.git && cd OneForAll
pip install -r requirements.txt
```
- **核心命令**:
```bash
python oneforall.py --target example.com run
python oneforall.py --targets ./targets.txt --valid run
```
- **输出解读**:结果存于 `results/` 目录的 xlsx/csv,含解析状态、CDN 标记、端口等信息;`--valid` 只保留验证通过的记录。

## DNS 查询

### dig(首选 DNS 工具)

- **用途**:查询各类 DNS 记录,调试解析问题,发现内部信息泄露(如 TXT 中的密钥、SPF 记录暴露的 IP)。
- **安装**:Linux 自带(bind9-utils);Windows 可用 `Resolve-DnsName` 替代。
- **核心命令**:
```bash
dig example.com A +short
dig example.com ANY +noall +answer          # 查询全部记录
dig -x 8.8.8.8 +short                       # 反向解析
dig example.com TXT +short                  # 检查 TXT(密钥/验证信息泄露)
dig @8.8.8.8 example.com MX                 # 指定 DNS 服务器
```
- **输出解读**:重点关注 TXT(SPF/DKIM/DMARC)、MX(邮件服务指纹)、NS(托管商)。`ANY` 在部分服务器被限制,可用具体类型替代。

### nslookup(Windows 内置)

- **用途**:Windows 环境快速查询,交互式与非交互式均可。
- **核心命令**:
```cmd
nslookup -type=A example.com 8.8.8.8
nslookup -type=TXT example.com
```
- **输出解读**:与 dig 类似;非交互模式一次一个查询,批量场景效率低。

### dnsrecon(DNS 综合探测)

- **用途**:DNS 枚举、区域传送测试、缓存投毒检测等,是 Kali 自带的全能 DNS 侦察工具。
- **安装**:`apt install dnsrecon`。
- **核心命令**:
```bash
dnsrecon -d example.com -t std                 # 标准枚举
dnsrecon -d example.com -t axfr                # 测试区域传送(常被忽略的高危配置)
dnsrecon -d example.com -D subdomains.txt -t brt  # 字典爆破
```
- **输出解读**:`AXFR` 成功即代表区域传送漏洞,可直接导出全部 DNS 记录;这是测试中优先尝试的点。

## 端口扫描

### nmap(端口扫描事实标准)

- **用途**:主机发现、端口扫描、服务版本与操作系统识别、漏洞脚本探测。
- **安装**:`apt install nmap`;Windows 安装包见官网。
- **常用参数**:
```bash
nmap -sS 192.168.1.0/24                    # SYN 半开扫描(需 root,快、隐蔽)
nmap -sT 192.168.1.1                       # TCP Connect 全连接扫描(无 root 时)
nmap -sV -p- 192.168.1.1                   # 全端口+服务版本识别(慢,先 -p- 再 -sV)
nmap -O 192.168.1.1                        # 操作系统识别(需 root,依赖端口开放情况)
nmap -p 80,443,8080,8443 192.168.1.1       # 指定端口
nmap -A 192.168.1.1                        # 综合扫描:-sV -O 脚本+ traceroute
nmap -T4 -sV -p 1-10000 192.168.1.1        # -T0~-T5 时序模板,值越大越快越易被发现
nmap --script=vuln 192.168.1.1             # 漏洞脚本扫描(NSE)
nmap -Pn 192.168.1.1                       # 跳过主机发现(目标禁 ping 时)
```
- **输出解读要点**:
  - `open`/`closed`/`filtered`:filtered 通常被防火墙拦,尝试 `-sT` 或 `-Pn` 确认。
  - 服务版本字段(如 `Apache httpd 2.4.49`)直接关联已知 CVE(如路径穿越 CVE-2021-41773)。
  - 高危端口速查:22(SSH)、23(Telnet)、445(SMB)、3389(RDP)、6379(Redis 未授权)、9200(ES 未授权)、27017(MongoDB 未授权)。
  - 输出格式:`-oA scan` 同时生成 nmap/nmap.gnmap/nmap.xml,便于后续工具消费与报告。

### masscan(高速端口扫描)

- **用途**:扫描超大规模网段(全网段 0.0.0.0/0 亦可行),速度可达每秒百万包,常用于资产测绘;仅做端口发现,不做版本识别。
- **安装**:`apt install masscan` 或源码编译。
- **核心命令**:
```bash
sudo masscan -p80,443,8080,8443 192.168.1.0/24 --rate 1000
sudo masscan -p1-65535 10.0.0.0/8 --rate 10000 -oL masscan.txt
```
- **输出解读**:结果文件每行 `open tcp 80 1.2.3.4 timestamp`;将结果转成 nmap 输入:`masscan --readscan masscan.txt | ...` 或用 `nmap -p <ports> -iL hosts.txt -sV` 二次确认。**注意**:高速扫描极易触发 IDS/防火墙告警与业务影响,务必评估授权范围与目标耐受度。

## HTTP 探测与指纹

### httpx(存活 Web 主机批量探测)

- **用途**:ProjectDiscovery 出品,对大量域名/IP 快速探测 HTTP 服务,提取标题、状态码、技术栈、CDN 等信息。
- **安装**:`go install github.com/projectdiscovery/httpx/cmd/httpx@latest`。
- **核心命令**:
```bash
cat live_subs.txt | httpx -title -status-code -tech-detect -silent
cat hosts.txt | httpx -ports 80,443,8080,8888 -title -json -o web.txt
httpx -l targets.txt -follow-redirects -web-server -cdn
```
- **输出解读**:`-tech-detect` 标记的框架(WordPress、ThinkPHP、Shiro 等)直接决定后续利用思路;`-cdn` 标记的资产后续扫描建议绕过 CDN 直连源站 IP。

### whatweb(指纹识别)

- **用途**:老牌 Web 指纹工具,识别 CMS、框架、服务器、JS 库等,内置数千指纹规则。
- **安装**:`apt install whatweb`。
- **核心命令**:
```bash
whatweb https://example.com
whatweb -a 3 -v https://example.com          # 更激进的探测级别(-a 1~4)
whatweb -i urls.txt --log-json=result.json   # 批量并输出 JSON
```
- **输出解读**:关注 `X-Powered-By`、CMS 版本(如 `WordPress[5.9]`)、`HTTPServer` 字段;版本号用于匹配已知漏洞。

### Wappalyzer(浏览器扩展)

- **用途**:浏览器插件,一键识别当前页面的技术栈(框架、CMS、分析工具、CDN),适合人工浏览时快速判断。
- **安装**:Chrome/Firefox 插件商店搜索 Wappalyzer;或使用其 CLI 版 `wappalyzer`(Node.js)。
- **使用**:访问目标页面点击图标,查看 Technologies 列表;可与 Burp 配合确认响应头。
- **输出解读**:技术栈列表用于制定攻击面清单,如检测到 `jQuery 3.5` 可查对应 XSS 利用链。

## 空间测绘(互联网资产搜索)

空间测绘引擎收录全球互联网资产指纹,可搜索特定产品、漏洞版本、开放端口,是红队与防御方(梳理暴露面)共用工具。注意合规:仅可用于授权目标查询,不得利用结果发起未授权攻击。

| 平台 | 网址 | 语法示例 | 说明 |
| --- | --- | --- | --- |
| Shodan | shodan.io | `product:"Apache" port:80 country:"CN"`、`http.title:"后台"`、`ssl.cert.subject.cn:"example.com"` | 全球最大,擅长端口/协议级指纹 |
| Fofa | fofa.info | `domain="example.com" && port="6379"`、`title="login" && country="CN"`、`icon_hash="..."` | 国产,语法灵活,支持图标反查 |
| Censys | censys.io | `services.service_name:"HTTP" AND services.port:8443` | 学术/研究背景,数据开放度好 |
| Hunter(鹰图) | hunter.qianxin.com | `domain="example.com"`、`web.body="xxx"`、`ip="1.2.3.4"` | 奇安信出品,Web 资产指纹丰富 |

- **进阶技巧**:用目标网站 favicon 的 `mmh3` 哈希在 Fofa/Shodan 反查同指纹资产;用证书 CN/SAN 字段找回同一主体的其他域名。
- **输出解读**:测绘结果用于(1)发现未授权暴露的数据库/管理后台;(2)找出真实 IP 绕过 CDN(对比证书、历史 DNS);(3)资产收敛自查。

## 目录枚举

### ffuf(高速模糊测试,推荐)

- **用途**:基于 Go 的高速 fuzzer,可做目录、参数、子域、vhost 爆破;速度远超 gobuster。
- **安装**:`go install github.com/ffuf/ffuf/v2@latest`。
- **核心命令**:
```bash
ffuf -u https://example.com/FUZZ -w /usr/share/wordlists/dirb/common.txt -mc 200,301,302,403 -o dir.json
ffuf -u https://example.com/FUZZ -w words.txt -x http://127.0.0.1:8080   # 走代理(便于 Burp 联动)
ffuf -u https://example.com -H "Host: FUZZ.example.com" -w vhosts.txt -fs 1234  # vhost 枚举,-fs 过滤响应大小
```
- **输出解读**:`-mc` 控制保留的状态码;用 `-fs/-fw/-fc` 过滤掉相同大小/字数的噪音响应;注意 403 目录可能是"存在但拒绝访问",常值得二次探测。

### gobuster(目录与 DNS 爆破)

- **用途**:经典目录/子域爆破工具,命令直观,适合快速上手。
- **安装**:`apt install gobuster` 或 `go install github.com/OJ/gobuster/v3@latest`。
- **核心命令**:
```bash
gobuster dir -u https://example.com -w common.txt -x php,html,bak,txt -t 50
gobuster dns -d example.com -w subdomains.txt -r 8.8.8.8
gobuster vhost -u https://example.com -w vhosts.txt
```
- **输出解读**:注意 `-x` 扩展名批量探测(备份文件 `.bak`/`.swp` 常泄露源码);`-t` 并发过高易触发 WAF,建议 10~50。

### dirsearch(Web 目录扫描)

- **用途**:Python 编写的目录扫描器,内置字典丰富,输出格式多样。
- **安装**:`git clone https://github.com/maurosoria/dirsearch.git && pip install -r requirements.txt`。
- **核心命令**:
```bash
python dirsearch.py -u https://example.com -e php,asp,html -t 20 --random-agent
python dirsearch.py -l urls.txt --format=json -o out.json
```
- **输出解读**:结果含状态码与响应大小;`.json`/`.csv` 输出便于汇入报告;`--random-agent` 降低被 WAF 拦概率。

## 证书透明日志(CT Logs)

- **用途**:所有公开 CA 签发的证书必须写入 CT 日志,因此可通过日志检索某域名的全部历史证书,挖掘未收录的子域(被动、不触达目标)。
- **安装**:无需安装,访问 https://crt.sh 或 https://crt.sh/?q=example.com 查询;命令行可用 `curl`。
- **核心命令**:
```bash
curl -s "https://crt.sh/?q=%25.example.com&output=json" | jq -r '.[].name_value' | sort -u
curl -s "https://crt.sh/?q=example.com&output=json" | jq -r '.[].common_name'
```
- **输出解读**:`%25` 为通配符编码(即 `%`);结果中 `*.example.com` 通配符证书条目可忽略,其余子域逐一验证;也可用 `certspotter`/`crt.sh` 的 API 轮询实现自动化监控。

## Git 泄露

- **用途**:目标站点若可访问 `.git` 目录,可还原源码、配置与密钥;gitleaks 则用于扫描代码仓库中已提交的敏感信息(防泄露视角)。
- **安装**:
```bash
git clone https://github.com/lijiejie/GitHack.git   # githack(旧称 GitHacker)
go install github.com/gitleaks/gitleaks/v8@latest    # gitleaks
```
- **核心命令**:
```bash
python GitHack.py https://example.com/.git/          # 还原 .git 中源码
gitleaks detect --source /path/to/repo --report-path report.json   # 扫描本地仓库
gitleaks git --remote https://github.com/xxx/repo.git -v           # 扫描远端仓库历史
```
- **输出解读**:
  - GitHack:还原出的源码重点搜索 `config.php`、`.env`、`application.yml`、`*.sql` 中的数据库口令与密钥。
  - gitleaks 报告按 `rule/secret/filename` 列出命中项;规则可在 `.gitleaks.toml` 中自定义。注意:仅可扫描你拥有或获授权的仓库。

## 信息收集工作流小结

```bash
# 以目标域 example.com 为例的被动+主动组合流程
subfinder -d example.com -silent | sort -u > subs.txt
cat subs.txt | dnsx -a -resp -silent > live.txt
cat live.txt | httpx -title -status-code -tech-detect -silent > web.txt
awk '{print $2}' live.txt | sort -u > ips.txt        # 提取 IP 去重
nmap -sS -sV -p- -T4 --min-rate 1000 -iL ips.txt -oA full   # 授权+速率控制
```
最终产物:资产清单(域名→IP→端口→服务→指纹)、潜在风险点列表,作为后续漏洞扫描与利用的输入。所有环节务必记录授权范围,超出即停。
