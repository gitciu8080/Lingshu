# 网络安全知识库 (Cybersecurity Knowledge Base)

> 关键词:网络安全知识库,攻防对抗,渗透测试,安全运维,安全维护,RAG,知识库索引,使用指南
> 面向网络安全攻防、渗透测试、安全运维、安全维护的检索增强生成(RAG)知识库。
> 本知识库设计为可被 RAG 系统直接索引的分块文档集合:每篇文档自包含、结构清晰、命令与要点可独立检索。

## 知识库定位

| --- | --- |
| 领域 | 网络安全攻防 / 渗透测试 / 安全运维 / 安全维护 |
| 语言 | 中文为主,保留英文技术术语与命令 |

| 用途 | 供 RAG 检索问答、安全人员速查、培训材料、工作流参考 |

## 使用方式(RAG 集成建议)

1. **分块策略**:建议按二级标题(`##`)分块,每块 300~800 token;代码块单独保留。
2. **索引字段**:以文件路径、H1 标题、文首关键词为元数据,写入向量库。
3. **检索问答**:常见问题如"SQL 注入如何检测"、"Linux 如何加固"、"护网蓝队怎么防守"等均可直接命中对应文档。
4. **扩展方式**:按 `NN-模块名/` 目录新增主题文件,并在 `META.json` 中登记。
