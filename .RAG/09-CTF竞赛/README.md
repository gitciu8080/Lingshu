> 本模块收录 CTF(Capture The Flag,夺旗赛)竞赛相关知识:赛事机制、题型分类、真题 Writeup 与解题技巧提炼。

## CTF 是什么

CTF(Capture The Flag,夺旗赛)是网络安全领域的主流竞赛形式。参赛者(个人或战队)通过解决一系列安全挑战获取"Flag"(通常是 `flag{...}` 或 `NCTF{...}` 格式的令牌)来得分。CTF 既是对安全技能的实战检验,也是攻防人才选拔与学习交流的重要平台。

常见赛制:

| 赛制 | 说明 | 特点 |
| --- | --- | --- |
| Jeopardy(解题制) | 平台发布多道分类题目,队伍逐题解答提交 Flag | 最主流,涵盖 Web/逆向/Pwn/密码/杂项等 |
| AWD(Attack With Defense) | 每队一套相同环境,既要攻破对手也要防守自己 | 攻防兼备,实时对抗,考验运维与应急能力 |
| AWD Plus | AWD 的进阶版,引入漏洞利用与流量审计 | 更贴近实战 |
| 靶场渗透 | 给定目标环境,模拟真实渗透过程 | 综合能力考察 |
| King of the Hill | 抢占并守住服务器"山头" | 对抗性强 |

## 学习方法

1. **按方向入门**:先掌握各方向基础(见上表关联模块),再刷入门题。
2. **刷题平台**:BUUCTF、NSSCTF、攻防世界、CTFshow 等;靶场:Vulnhub、HackTheBox。
3. **读 Writeup**:读完动手复现,重点理解**思路**而非代码本身。
4. **工具熟练**:掌握 01-渗透测试 与 06-安全工具 模块列出的工具链。
5. **赛事参与**:关注各大高校与厂商赛事(NCTF/强网杯/护网杯/CTF 竞赛平台)。

## 合规声明

CTF 题目均在主办方提供的隔离环境/靶机中进行,任何利用手法仅在题目环境与授权范围内有效。将 CTF 技巧用于未经授权的真实系统属违法行为。
