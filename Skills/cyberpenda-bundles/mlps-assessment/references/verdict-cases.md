# 等保三级计算环境 判定判例速查

> 关键词:等保三级、测评单元、判定判例、身份鉴别、访问控制、安全审计、入侵防范

## 身份鉴别

| 核查点 | 命令 | 符合 | 部分符合 | 不符合 |
|---|---|---|---|---|
| 口令周期 | chage -l / login.defs | ≤90 天有复杂度 | 90-180 天 | 无策略或 >180 |
| 登录失败处理 | pam_faillock 配置 | deny≤5 + unlock_time | 有模块未生效 | 无 |
| 远程加密 | sshd PasswordAuthentication | no（密钥）| yes 但强口令 | 允许空口令 |
| 双因素 | 管理员登录方式 | 有双因素 | 单因素+严格审计 | 单因素弱口令 |

## 访问控制

| 核查点 | 命令 | 判定要点 |
|---|---|---|
| 特权账户 | awk -F: '$3==0' /etc/passwd | 仅 root 符合；多账户不符合 |
| 默认账户改名/禁用 | 检查 adm/lp 等 shell | /sbin/nologin 符合 |
| 共享账户 | last 与 /etc/passwd 对照 | 一人一号符合 |
| umask | profile/bashrc | 027 及更严符合 |

## 安全审计

| 核查点 | 判定 |
|---|---|
| auditd 运行 + 规则覆盖用户/权限变更 | 符合 |
| rsyslog 远程集中收集 | 加分项，缺失不单独判不符合 |
| 日志留存 ≥6 个月 | 不足为部分符合/不符合 |

## 入侵防范

| 核查点 | 判定 |
|---|---|
| 最小安装（无多余包/服务）| 有 telnet/rsh 等即不符合 |
| 高危端口 | 23/3389 对外开放不符合 |
| 补丁 | 无高危漏洞补丁缺失记录即符合 |

## 恶意代码防范 / 数据安全

- clamav 或 EDR 运行 → 符合；无 → 不符合
- 远程管理走 SSH/HTTPS → 符合；telnet/http 明文管理 → 不符合
- 口令存储 sha512（/etc/shadow $6$）→ 符合；md5 → 不符合
